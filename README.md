# SkillJoiner starter website

A responsive education/career opportunities website inspired by the general information architecture of modern opportunity blogs.

## Files
- index.html — page structure and SEO metadata
- style.css — responsive styling
- script.js — search, load-more, mobile menu and newsletter demo

## Run
Open `index.html` in a browser. No build system is required.

## Customize
1. Change the SkillJoiner brand in `index.html`.
2. Replace the sample posts in `script.js` with your own content.
3. Replace placeholder ad boxes with your approved ad network code.
4. Connect the newsletter form to your email provider/backend.
5. Add real article pages and a CMS/database when you're ready.

The template intentionally uses original branding, sample content and CSS rather than copying another site's proprietary text, logo or media.
